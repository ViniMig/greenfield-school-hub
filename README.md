# Greenfield School Hub

Build a mockup of a school website. The school's theme colors are green and blue. I want a modern looking website, with a responsive layout. The landing page should display some kind of welcome section, a section for latest news and some "quick navigation" section with some relevant links to other pages of the website. give a few options to the menu on the top and make it either a sticky menu or disappear on scroll and reappear if we move the cursor.
